Sequências: PA e PG

Uma escada em que cada degrau sobe o mesmo tanto, ou uma bactéria que dobra a cada hora? A primeira cresce somando sempre o mesmo número: é uma PA. A segunda cresce multiplicando: é uma PG, e ela dispara muito mais rápido. Juros compostos, epidemias e prestações vivem disso.

Monte a sequência escolha o tipo, o primeiro termo e a razão

Progressão aritmética (PA)

  • Cada termo = o anterior + r. Ex.: 3, 7, 11, 15… (r = 4).
  • Termo geral: aₙ = a₁ + (n − 1) · r. O 20º termo de 3, 7, 11… é 3 + 19 × 4 = 79.
  • Soma dos n primeiros: Sₙ = (a₁ + aₙ) · n ÷ 2. Truque de Gauss: o primeiro + o último = o segundo + o penúltimo…
  • No gráfico, os pontos de uma PA ficam numa reta: é uma função afim.

Progressão geométrica (PG)

  • Cada termo = o anterior × q. Ex.: 3, 6, 12, 24… (q = 2).
  • Termo geral: aₙ = a₁ · qⁿ⁻¹.
  • Com q > 1, cresce como a exponencial; com 0 < q < 1, vai diminuindo (meia-vida, depreciação).
  • Juros compostos são uma PG: a cada mês, o valor é multiplicado por (1 + taxa).
